# Resenha 2.2 — rankings públicos

## Atualização obrigatória do Supabase

1. Abra o projeto no Supabase.
2. Entre em **SQL Editor**.
3. Copie todo o conteúdo de `supabase/schema.sql`.
4. Execute o script completo.

O script mantém os dados existentes e amplia a função pública do Mural. Visitantes continuam sem permissão para alterar qualquer informação.

## Novidades do Mural

- ranking geral da carreira por modalidade;
- média mensal com seleção do mês;
- ranking de cada partida com seleção pelo placar e pela data;
- destaques atualizados conforme a classificação selecionada;
- funcionamento independente da paginação do histórico exibido na tela.

Depois de executar o SQL, substitua os arquivos do repositório, faça `commit` e `push`. O GitHub Pages publicará a atualização pelo workflow existente.
