# Resenha 2.14.2 — modalidades no mural e no login

## Novidades

- Arte de futebol nos rankings de Futebol, Futebol Society e Futebol de Salão.
- Arte exclusiva nos rankings de Vôlei e Basquete.
- Carrossel automático no login com mascote, futebol, vôlei e basquete.
- Troca suave a cada 4,5 segundos e indicadores para navegação manual.
- Todas as imagens usam uma área fixa para evitar deslocamentos do formulário.
- Responsividade ajustada para computador, tablet e celular.
- A preferência do sistema por menos animações é respeitada.
- Indicadores em bolinhas removidos para deixar o login mais limpo.
- Imagens do login alinhadas pela base e proporcionais ao bloco de texto.
- Artes dos rankings reenquadradas para preservar rostos, uniformes e bola.
- Conjunto visual do login centralizado verticalmente, sem concentração na parte inferior.
- Personagens ampliados para aproveitar melhor a área esquerda em telas grandes.

## Atualização

Preserve o `.env` local e os _secrets_ configurados no GitHub. Substitua os demais arquivos e execute:

```bash
npm install
npm run build
```

Depois envie as alterações ao GitHub para publicar a nova versão.
