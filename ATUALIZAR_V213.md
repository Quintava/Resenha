# Resenha 2.13.0 — atualização visual

## O que mudou

- Novo ícone oficial com bola de futebol nas cores do mascote.
- Ícone aplicado no cabeçalho, login, recuperação de senha, notificações, favicon e instalação PWA.
- Emblema anterior reposicionado no rodapé ao lado do crédito do desenvolvedor.
- Login realinhado pela base: texto e mascote agora terminam na mesma linha visual.
- Ajustes responsivos do rodapé e da apresentação do login em computador, tablet e celular.

## Como atualizar

Substitua os arquivos do projeto pelos deste pacote, mantendo o seu `.env` local e os _secrets_ já configurados no GitHub. Depois execute:

```bash
npm install
npm run build
```

Se o build terminar sem erros, envie as alterações ao GitHub para disparar a publicação.
