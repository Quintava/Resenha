# Resenha 2.3.1 — banco geral da resenha

## Funcionamento

- Com **Banco geral da resenha** desmarcado, cada time pode usar somente os próprios reservas.
- Com a opção marcada, qualquer jogador do banco pode entrar manualmente em qualquer um dos dois times.
- A mesma regra vale para a entrada de um novo goleiro vindo do banco.
- Ao finalizar a partida, nenhuma substituição é feita automaticamente e a escalação atual permanece pronta para o jogo seguinte.

Na tela da partida, o banco geral aparece em um bloco único. As trocas continuam sendo registradas ao tocar no jogador que vai sair.

## Publicação

Substitua os arquivos do repositório e faça `commit` e `push`. Esta atualização não cria novas tabelas. Quem ainda não executou o `schema.sql` da versão 2.2 deve executá-lo no SQL Editor do Supabase para manter os rankings públicos funcionando.
